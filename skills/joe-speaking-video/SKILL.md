# Recording to episode

This is a portable teaching adaptation, not Joe’s original installed project. The earlier workflow was demonstrated inside the Stripe film. It is useful for a different job than a cinematic evidence-led film.

A recording of your own talk at an event has its own Skill: joe-speaking-talk-cut.

## Read first
Read [workflow.md](references/workflow.md) and the [input brief](examples/input-brief.md). Use the current request and available files to fill gaps; ask only for missing decisions that affect the edit.

## Inputs
recording / desired orientation / destination / corrected transcript / approved identity assets.

Confirm source access and identify the current editable project or build one suited to the requested output. Never claim that this instruction folder contains a working renderer. Use a Remotion project, FFmpeg or existing local tools as appropriate; return exact run instructions with the editable project.

## Work in visible stages
1. Inspect source dimensions, duration, audio and transcript. Keep originals unchanged.
2. Propose the story or segment and the necessary caption corrections, using source timestamps. Do not invent quotes, performance outcomes or endorsements.
3. Produce one playable draft with the agreed scope. Keep speech at its original speed unless the creator requests a change.
4. Ask the creator to identify the problem, change and elements to preserve. Revise only that section; save a new filename.
5. Check complete speech, readable captions, crop, transitions and audio. A still image does not verify sound or motion.
6. Deliver the accepted movie, matching cover, concise post copy and editable project with dependency versions and render instructions. Make each cover fit the crop its platform applies: RedNote crops a landscape video’s cover to 4:3, so a 16:9 frame loses its left side there; upload a 4:3 cover instead. Include a short verification note and limitations. Publishing remains a separate action.

Follow the specific selection and review rules in the workflow reference. Use the supplied identity and assets; do not assume Joe’s templates or branding exist.

## Example invocation
Read the supplied recording and notes. Use this Skill to draft the transcript and episode plan. Preserve original speech and meaning. Return the proposed cuts and caption corrections before the full edit.

## Done means
The creator has watched the export and accepted it, the destination crop has been checked, and the source project remains reproducible. Technical checks alone are not creative approval.
